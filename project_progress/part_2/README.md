## How to reproduce the results

1. Set up the environment as in Part 1 (see the main `README.md`; Python ≥ 3.10, we used the same packages, no new one is needed;
   `scikit-learn` is optional: if it is installed, `test_part2.py` also compares NDCG and AP with it).
2. The data files go in `data/` (they are not committed, see `.gitignore`):
   ```
   data/fashion_products_dataset.json
   data/validation_labels.csv
   ```
3. Run the notebook from this folder. It uses `data/processed_corpus.pkl` (written by the Part 1 notebook) and, if the file is
   missing, it creates it with the Part 1 pre-processing (~35 s). **Nothing of `project_progress/part_1` is modified.**
   ```bash
   cd project_progress/part_2
   jupyter notebook indexing_evaluation.ipynb          # interactive
   # or, non-interactive (~1 min):
   jupyter nbconvert --to notebook --execute --inplace indexing_evaluation.ipynb
   ```
4. Tests (they are also run inside the notebook) and the independent check of the reported numbers:
   ```bash
   python test_part2.py        # or: python -m pytest test_part2.py
   python check_metrics.py     # run after the notebook: prints ALL MATCH
   ```

Running the notebook rewrites `results/`, `figures/` and `relevance_judgments.csv`.

## Summary of the decisions

- **Index:** on the merged field `all_terms` of Part 1; `postings[term_id] = [(doc_id, tf), ...]` sorted by doc id.
  Conjunctive queries intersect the lists from the rarest term to the most frequent one.
- **Ranking:** cosine similarity with `(1 + log10 tf) * log10(N / df)` weights for documents and queries; the document norm is
  computed over all the terms of the document; ties are broken by doc id.
- **Test queries:** chosen with the terms that carry most TF-IDF weight in the collection; each one tests a different behaviour.
- **Validation queries:** the ranking of the system is reduced to the judged documents (condensed list), keeping the judged
  documents that the system does not return in `R`. The two other protocols are shown in the notebook only for the analysis.
- **Our judgments:** written guidelines, applied to all 28,080 documents for every query; reviewed by reading the returned
  documents and the relevant documents that are not returned.
- **Limitations:** measured with experiments that change one thing at a time (other ranking functions, relaxed AND, modified
  pre-processing). The modified pre-processing is applied inside the notebook only, the Part 1 files are not changed.
